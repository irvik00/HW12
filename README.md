- Wireshark / tshark
- GitHub

```
many_interfaces.pcapng
```

## 🔍 Этап 2. Извлечение ключевых артефактов

В ходе анализа были извлечены:

### 1️⃣ IP-соединения
- IPv4 и IPv6 адреса
- Источники и назначения
- Транспортный протокол

Результат сохранён в:
```
results/ip_connections.csv
```

### 2️⃣ DNS-запросы и ответы
- Доменные имена
- Тип записи (QUERY / RESPONSE)
- Временная метка

Результат сохранён в:
```
results/dns_queries.csv
```

### 3️⃣ Статистика протоколов
Подсчитано распределение протоколов по количеству пакетов.

## 📊 Этап 3. Визуализация

Создан график распределения протоколов:

results/protocol_distribution.png

## ▶ Как запустить

1. Установить зависимости:

```
pip install pyshark pandas matplotlib
```

2. Убедиться, что установлен tshark:

```
tshark -v
```

3. Запустить скрипт:

```
python analyzer.py
```
